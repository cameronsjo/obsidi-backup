# Agent Instructions

This project tracks issues on GitHub. `bd` (beads) was retired per
[cadence-groundwork#138](https://github.com/cameronsjo/cadence-groundwork/issues/138) —
`.beads/` is dormant historical data, not the work queue.

## Session Completion

Wrap up a work session the normal way: file GitHub issues for remaining work,
run quality gates if code changed, commit, and push. If you're using Claude
Code with the cadence plugin, `cadence:outro` covers this.
